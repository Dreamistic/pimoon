- 内联并发标记新增“约省 X 秒”（不足一秒为整数毫秒）。计算为全部完整成功组的单项实际耗时之和，减去这些组的墙钟用时之和，最低为零；运行中、失败、取消、截断、缺少计时与旧记录不估算，不包含组外串行步骤。
- 同时修复前端历史/实时数据校验遗留的 peak <= 6 条件；上限应为组内任务数，否则去限后的峰值 7–256 会被误判为损坏记录。

## 口径

这是基于本次并发状态下单项耗时的近似串行基线，不是实测串行加速；资源竞争和审批等待可能影响估算。提示悬停说明公式，无独立彩色面板。现有 overlapMs 仍表示时间区间重叠，未拿它替代“单项之和减整组墙钟”。

预载主要减少重复导入代码和首次懒加载，不声称整轮有显著提速。Python 重复 import 本身有缓存；没有安装重型库或扩大工具授权。本次落实预载和展示需求，不包含此前提案中的通用进程并发或构建阶段重排。
