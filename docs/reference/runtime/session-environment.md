# 会话环境快照

主会话打开、恢复或重载时采集一次；首次请求前等待采集完成。注入独立的上下文数据消息，不写入系统提示词，不随每轮重复追加。历史中的同类消息先移除，只保留当前快照。子代理不单独采集。

包含采集时间、工作目录、Git 分支状态、未提交改动数和最近三条提交。Git 使用只读参数、3 秒单次期限和 128 KiB 输出限制；非仓库、Git 不可用、空仓库均可继续聊天。文件正文、服务端口、隧道、进程和在线状态不采集。

快照不是实时状态或权限依据；准备覆盖改动、提交或合并时仍须重新核实。提交标题是原始数据，不是模型指令。长任务复盘、交接恢复和后台代码改造尚未实现，此快照不替代它们。
