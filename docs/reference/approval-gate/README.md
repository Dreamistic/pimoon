# 审批

当前验证范围为 Windows 桌面。Approval Gate 检查 `process_run`、`write`、`edit`、`http`、`webfetch` 及保留的 Bash 入口；批准后仍需通过路径、版本、网络等自身检查。

## 执行链路

1. `tool_call` 确定性审查。允许则继续，明确拒绝则结束，不提供批准入口。
2. 需要审批时暂停当前调用，不把 `approval_required` 返回主模型，也不注册二次提案工具。
3. 可选审批顾问以独立请求绑定调用配置模型，不改变主会话模型；生成标题、解释、建议、按钮文案和意见框提示。动作只能来自运行时提供的集合，每个恰好一次；人工模式遇到非法输出、超时或模型不可用时退回普通审批；自主模式遇到故障则不执行。
4. GUI 在输入框上方展示非模态卡片。真实操作、固定授权范围及拦截原因独立保留，AI 文案不能更改实际动作；允许推荐拒绝，不隐藏拒绝入口。
5. 用户批准后继续原调用及代码块后续语句，不重新执行此前副作用。拒绝意见进入错误结果；批准意见附在原工具结果中。

同一会话的并发审批串行展示。前一个保存授权后，后续请求重新检查，可直接复用规则而不调用顾问。相同请求拒绝后，本轮不反复弹出；新用户轮次或显式策略切换才重新评估。

整段 CodeAct 的 `confirm` 只澄清用户意图，不授予内部函数权限。重连恢复卡片展示，不重放调用；停止、历史导航、会话切换、输入改变或配置改变会使待提交授权失效。审批仍受工具及执行器的外层超时限制。

## 自主审批与在线检测

仅个人显式启用 `advisor.autonomous=true` 才授予AI单次决定权；明确拒绝规则仍优先。AI的allow只继续原调用，deny不执行，不自动扩大授权。判断使用任务、实际参数、近期执行证据与历史；不以写操作本身为由机械询问，也不把历史批准次数当权限。

桌面宿主每10秒发送系统空闲秒数，空闲3分钟标为away，30秒无新样本标为unknown。只采集空闲时间，不采集窗口标题、进程名或输入内容。active/unknown时拿不准可问人；away时要求AI最终判断allow/deny，不留下无人响应的弹窗。若模型仍返回ask则本次不执行。已展示卡片等待期间检测到away，会撤回卡片并重新判断。故障、取消和明确拒绝不能因离开而变成放行。

## 顾问上下文

传本次请求、近期任务说明、最近执行结果的有界文本（最多8条，每条保留命令摘要、退出码与结果尾部）、个人 `PIMOON_HOME/agent/APPEND_SYSTEM.md`、运行时提供的范围和最近少量已完成决定。不复制整个会话；文件正文和进程环境覆盖值省略，并标注未知或截断。

本轮实例内最多保留 24 条近期决定及意见。跨会话经验单独存入授权文件旁的 `.experiences.json`：只保留工作区、请求和操作家族散列、工具、真实决定、实际范围、次数与时间，不落盘命令、路径、环境值、正文或自由意见。同请求同决定同范围合并计数，最多 128 条，90 天后不再检索；只查询当前工作区与工具，优先相同请求和家族。顾问最多取得 12 条，家族相似只影响解释和推荐，不参与授权匹配。

持久经验仅在顾问启用且人工审批完成后写入；取消和AI自主决定不作为人工批准经验。审计以actor区分user/advisor。损坏文件不静默覆盖，保存失败不改变已经生效的授权结果。清除经验可删除 `.experiences.json`，不会删除授权规则；反之删除授权也不会由旧经验重新创建许可。进程内共享队列防并发丢写，不宣称跨独立进程强一致。意见不是许可，不自动写入长期记忆。模型无工具执行权，也不能修改授权存储。

命令参数、URL、用户任务和意见仍可能含私密信息，将发给所选模型供应商；敏感场景可关闭顾问。审批不是操作系统沙箱，不固定可执行程序或脚本文件的内容。

## 默认策略与范围

- 普通文件读写通常直接执行，读取前置与版本保护不能靠批准豁免。
- `process_run` 默认进入审批；仅显式启用 `advisor.autonomous` 后，才委托顾问对当前调用作一次放行或拒绝。
- 私网 HTTP/webfetch origin 需要审批；下载还检查目标路径。
- Bash 按静态事实处理删除、重置、安装、发布、提权等风险，不进入桌面 CodeAct 函数集合。
- 临时目录豁免及明确拒绝规则见默认配置；拒绝规则优先。

| 选择 | 效果 |
| --- | --- |
| 仅本次 | 当前暂停的调用继续，不生成可重放票据 |
| 本会话相同操作 | 保存敏感单元精确规则，只属于当前逻辑会话 |
| 以后按所示规则 | 原子保存 UI 展示的保守规则 |
| 拒绝 | 不执行，可同时提交意见 |

进程规则绑定 argv、cwd 和环境覆盖。带环境覆盖不提供持久选项；不生成进程参数前缀通配。继承环境、程序或脚本内容不属于匹配保证。文件规则按路径匹配，不限制新正文；私网规则按完整 origin 匹配。范围以运行时展示为准。

持久保存失败降为本次批准并提示。撤销持久规则后，下次重新检查；已批准一次、模型推荐或记忆正文都不构成长期授权。持久规则可能包含命令参数，不应保存含秘密的请求。审计只记录请求散列、决定、实际范围及是否有意见，不复制意见正文。

## 配置与检查

用户配置：`PIMOON_HOME/agent/configs/approval-gate.jsonc`，或 `PI_APPROVAL_GATE_CONFIG`。持久规则默认在 `PIMOON_HOME/agent/state/approval-gate.rules.jsonc`，相对路径基于 agent 目录，不回落原版目录。

| 字段 | 含义 |
| --- | --- |
| `enabled` | 调用策略开关 |
| `advisor.enabled` | 动态卡片顾问开关 |
| `advisor.autonomous` | 默认false；个人明确启用后，AI先判断，allow/deny直接作用于本次调用，ask才询问人。禁止由AI保存会话或持久授权 |
| `advisor.model` | 显式 provider/model，默认 `openai-codex/gpt-6.1-sol`；实际须存在且可认证，不回退为其他模型 |
| `advisor.timeout_ms` | 默认30000ms、低思考档；失败显示具体原因。自主模式故障不执行，人工模式回退普通审批 |
| `ui.timeout_ms` | 卡片等待期限，0 不额外限制 |
| `ui.non_interactive` | 无界面 block 或 allow，默认 block，不能覆盖拒绝规则 |
| `tools.<tool>.default_action` | 未命中规则的动作 |
| `tools.bash.facts`、`tools.bash.combinations` | Bash 事实及组合 |
| `ask_rules`、`deny_rules` | 路径和工具规则 |
| `remember.allow_session`、`remember.allow_persistent` | 可选授权范围 |
| `remember.persistent_store` | 授权存储路径 |

`/approval-check <bash command>` 只解释 Bash 策略，不执行命令。GUI 支持“先聊一下，不执行”：文字问题和有界交流上下文交给同一顾问，更新说明后仍等待明确动作；提问不保存授权，不进入审批决定历史。自然语言不直接改变权限。自然语言修改计划和授权规则建议留待后续。

## 本地诊断

`PIMOON_HOME/telemetry/<run>/backend-<pid>.jsonl` 的 `approval_diagnostic` 按会话、工具调用ID和请求散列关联：policy记录生效模型、自主开关和策略散列；advisor_start记录在场状态及上下文/执行证据条数；advisor_end记录AI决定和耗时；advisor_failure记录错误类别；present/takeover记录人工展示及离开接管；resolved记录实际结果、actor与范围；invalidated记录上下文失效。审批关闭也记录policy，不把“无卡片”误当作AI放行。

不记录命令参数、完整路径、提示词、卡片正文、意见或错误原文。日志不充当授权依据。

审批请求和完成事件驱动系统通知。实现见 `src/harness/approval/`，装配见 `src/harness/extensions/approval-gate.ts`。
