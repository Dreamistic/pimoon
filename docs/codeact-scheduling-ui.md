# 显式并发执行界面

## 用户可见行为

- 并发是工具调用的执行属性，不另设彩色面板、逐项时间线或重复的操作列表。
- 执行标题内以无底色、中性色的小图标与文字显示“并发 · 峰值 N”；实际峰值不超过1时显示“并发组”。没有显式组时不增加标记，旧记录仍可显示已保存的并发峰值。
- 展开后沿用现有子工具调用列表、状态图标和折叠动效；并发标记本身不循环闪烁、不增加入场动画。手动折叠仍优先于实时更新。
- 标记说明明确峰值不是提速倍数。不凭源码、函数数量或参数猜测并发。

## 实现边界

- Runtime 在真实调度开始/结束边界采样，独立回调通过 execute 的 SDK 进度更新进入正式 GUI；最终 details.scheduling 留在会话记录，重开和大输出引用仍可读取。
- 不改变并发算法、工具权限、失败策略或副作用顺序。调度路径/目标不进入数值遥测，元数据也不进入模型正文。
- 单次执行最多保存32组、256项详情，目标最多160字符；达到上限明确标记截断。分组统计仍按实际事件记录，不把未展示项当未执行。
- 进度最多每80ms刷新一次，组开始/结束立即刷新；末尾更新与取消清理计时器。回调不可用不改变业务执行。
- 标记使用现有辅助文字颜色和字号，随标题换行；不新增弹窗或抢焦点操作。
