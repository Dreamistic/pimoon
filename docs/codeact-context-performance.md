# CodeAct 上下文、截流用量与搜索预算

2026-11-05。此次不改审批顾问、不切换模型或执行协议，不运行真实模型补账请求，也不覆盖桌面构建。

## 可恢复裁剪

之前 `/prune` 只识别原生 toolCall/toolResult，文本 CodeAct 的大结果无法进入候选。现在支持：

- 只关联唯一、按顺序闭合的 CodeAct 执行与结果。
- 保留所有执行代码、用户约束、最近两次结果、错误/部分失败及已识别的修改、进程输出。
- 更早且有完整成功查询调用记录的输出，达到 2k 字符或包含图片时可裁剪。纯 Python、未知调用、不完整调用记录不作为候选。
- 只在模型上下文中将输出替换为带 ID 的标记；原始会话正文和图片不改写。`/prune restore` 只恢复上下文，不执行代码。缺失原事务时拒绝伪造恢复。
- 成本预览使用实际文本 CodeAct 转换后的内容计算变化前缀，不把已改变的输出后缀当缓存命中。不使用截流的部分 usage 作为完整缓存证据。

仍是手动命令，不自动删除历史，也不添加摘要模型调用：`/prune` 做目录价格与缓存失效预览；`/prune force` 跳过价格判断但保留候选保护；`/prune restore` 恢复最近一次未撤销的裁剪。

### 本机历史只读投影

对一段包含 369 条消息的历史上下文，在隔离环境中只读、内存投影，没有向真实会话写裁剪状态或重放代码：

| 指标 | 原投影 | 裁剪投影 |
| --- | ---: | ---: |
| 可见文本字符，同口径 | 1,387,354 | 1,000,043 |
| 可见文本 Token 估算 | 430,692 | 314,059 |
| 裁剪旧查询结果 | 0 | 21 |

可见文本约减少 27.9%，本地 Token 估算约减少 27.1%。这是统一 o200k_base 的历史投影估算，不是供应商完整请求计量、现金费用或时延收益证明。执行代码和保护范围保留，不能据此承诺所有会话都减少相同比例；缓存失效还可能使下一次请求变慢。

## 截流用量完整性

执行块闭合时不再立即取消源流：给**同一响应**最多 250 ms 的正常终态回收窗口，收集已经临近返回的完整 usage。完整终态的响应 ID 与执行前思考块的签名继续保留，执行块后的文本和新思考均不进入展示或回放，也不会执行后缀内容。

- 窗口内收到 error/length 不将代码当作成功执行；用户取消优先。
- 超过窗口仍按原截流路径取消并收尾，不无限等模型、不额外请求、不伪造用量。
- 这可能增加最多 250 ms 等待和窗口内的服务端生成。只能改善完整性，不能保证所有响应都有完整 usage，更不能还原旧截流记录。
- 消息和会话统计对不完整用量标明“已报告/已知部分”；不完整的最近一轮和全会话均值不伪装为完整统计。目录价格费用估算仍不是实际订阅账单。
- 用量状态判断拆为不依赖分词器的纯模块，GUI 不为显示完整性引入 BPE 词表。

离线流测试覆盖：闭合后 20 ms 返回真实终态用量、窗口超时、迟到的 error/length、用户取消及计时器释放。没有真实模型新样本，因此不报告新的完整率或速度排名。

## 搜索预算与局部采样

同一 GrepTool 的多个查询共享扫描并发预算，上限为逻辑核数一半且最多 8、至少 1。排队查询可独立取消，不影响其他查询。没有合并权限裁决、跳过路径保护/版本复验，也没有改变搜索和排序语义。

新增离线基准：

```text
bun scripts/bench-codeact-search.mjs 3 --concurrent
```

同机对四个查询分三批采样，比较的是整批墙钟，不是四条耗时之和：

| 测量 | 无共享预算 | 有共享预算 |
| --- | ---: | ---: |
| 第 1 批 | 7.274 s | 5.964 s |
| 第 2 批 | 6.078 s | 5.489 s |
| 第 3 批 | 5.406 s | 5.023 s |
| 中位数 | 6.078 s | 5.489 s |

两组均遍历 1,821 个条目、搜索 1,518 个文件，各查询命中数和截断原因一致；实现开关对应的源码行使搜索字节数相差 29 字节。未出现 entry_limit 漏扫。先后执行、文件系统缓存和系统负载会影响结果；同步采集的单查询也有变快，因此**不能将约 9.7% 的批次中位数差全部归因于共享预算或声称稳定加速**。确定性的变化是扫描资源不再按并发查询数倍增；取消隔离及结果正确性有真实文件流程测试。

原始记录保留在本地忽略目录：

- 探索性基线：`.tmp/tests/search-benchmark/run-YBFOVv/`；首次改动采样：`run-fnCu7G/`，不混入上述对比。
- 同文件数量的无预算并发：`run-1wUdrs/`；共享预算并发：`run-ylcL9O/`。
- 单查询对照：`run-2R52bN/`、`run-qXhrLN/`，仅用于检查是否观察到明显回退，不证明稳定收益。
